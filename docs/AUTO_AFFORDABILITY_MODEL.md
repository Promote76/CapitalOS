# Auto Affordability Model

Vehicle affordability is a scenario, not an approval. Total monthly ownership
cost includes payment, insurance, fuel, maintenance reserve, registration,
parking/tolls, and other monthly cost.

The primary test is floor-first:

- household shortfall risk if the new operating budget exceeds the floor;
- capital-goal impact if the vehicle consumes the modeled floor surplus;
- affordable-but-tight when the floor buffer is thin;
- affordable-with-buffer only when the floor remains supported.

No vehicle scenario moves money, changes Safe-to-Deploy, or authorizes a
purchase.
