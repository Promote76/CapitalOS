# Blockchain Future Boundary

Blockchain adapters are intentionally disabled. Arbitrum is the preferred future chain, with Base and Ethereum represented as disabled peers for interface compatibility.

Future chain work may support read-only status, simulation, and reconciliation before any submission capability is considered. Household finance data, account credentials, private planning information, and financial snapshots remain off-chain.

There is no wallet connection, smart-contract deployment, live transaction submission, or autonomous capital movement in the current system.
